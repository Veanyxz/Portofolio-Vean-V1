# Vean Portfolio

Portofolio pribadi Vean — full-stack developer & security researcher.

Live: https://vean.my.id

## Stack
- Static HTML / CSS / JS (no build step)
- Dark terminal/industrial theme, accent `#00ff9c`
- Fonts: Space Grotesk + Inter + JetBrains Mono (Google Fonts)
- Animations: boot preloader, glitch name, typing role, scroll reveal, counters, cursor glow

## Edit konten
Semua data (proyek, stack, role) ada di `public/app.js` bagian `DATA`.

## Deploy
Netlify — `publish = public`, lihat `netlify.toml`.
